Privacy Policy

Last updated: November 7, 2026

This Privacy Policy explains how "Viral Minute Uploader" (the "Tool"), operated by [YOUR NAME] for the YouTube channel The Viral Minute, collects, uses, stores and shares information. The Tool is a private application used only by its owner to manage the owner's own YouTube channel. It is not offered to the public.

YouTube API Services

The Tool uses YouTube API Services. By using the Tool, you agree to be bound by the YouTube Terms of Service. Information accessed through YouTube API Services is also subject to the Google Privacy Policy.

Information the Tool accesses

  • Google account authorization: an OAuth access token that lets the Tool upload videos to the authorized channel (scope youtube.upload) and read public YouTube data (scope youtube.readonly).
  • Public YouTube data: titles and view counts of publicly listed trending videos, used only to choose topics for new videos.
  • Upload results: the ID of each video the Tool uploads to the owner's channel.

The Tool does not access other users' private data, comments, subscribers, messages or payment information.

How the information is used

  • To upload videos created by the owner to the owner's own YouTube channel.
  • To see which public topics are currently trending, so new videos cover relevant subjects.
  • To keep a list of already covered topics, so videos are not repeated.

Storage and retention

The OAuth token is stored only on the owner's own computer, in a local file. Trending video titles are kept in memory for the duration of a single run and are not stored. The list of covered topics and uploaded video IDs is stored locally on the owner's computer. No data is stored on any external server operated by the Tool.

Sharing

The Tool does not sell, rent or share any user data with third parties. To write original scripts, the titles of public trending videos and topics are sent to an AI text service (Anthropic). No personal data or account credentials are included in these requests.

Cookies

This website and the Tool do not use cookies or tracking technologies, and do not store or read information on your device through a browser.

Revoking access

You can revoke the Tool's access to your Google account at any time on the Google security settings page (also available at security.google.com/settings/security/permissions). After revocation, the locally stored token stops working and can be deleted. To request deletion of any stored data, email the address below; it will be deleted within 7 days.
